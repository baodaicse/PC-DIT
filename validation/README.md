# CPU-DIT-01 Validation Records

Thư mục này giữ control files nhỏ cho validation. Evidence lớn lấy từ USB không
nên commit mặc định; lưu theo cấu trúc trong
[`docs/VALIDATION_GUIDE.md`](../docs/VALIDATION_GUIDE.md).

- [`VALIDATION_STATUS.md`](VALIDATION_STATUS.md): trạng thái release chính thức.
- [`MATRIX.csv`](MATRIX.csv): ma trận bắt buộc và trạng thái từng cấu hình.
- [`RUN_RECORD_TEMPLATE.md`](RUN_RECORD_TEMPLATE.md): mẫu biên bản cho một config.

Chỉ đổi trạng thái sau khi report gốc, checksum và reviewer evidence tồn tại.
